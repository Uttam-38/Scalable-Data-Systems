# Relational Database Design & Query Optimization

## Overview
This project focuses on designing and implementing a relational database system
for large-scale data ingestion and analytical querying. The goal was to model
structured data effectively, enforce data integrity using constraints, and
execute complex analytical SQL queries efficiently.

The project emphasizes working with real-world sized datasets and understanding
how schema design and query formulation impact performance.

## Objectives
- Design normalized relational schemas
- Define primary keys, foreign keys, and integrity constraints
- Load large datasets efficiently into PostgreSQL
- Implement analytical SQL queries involving joins and aggregation
- Store query results in materialized tables

## Dataset
The dataset consists of structured records representing online platform data
across multiple entities. Due to size and licensing restrictions, the dataset
files are not included in this repository.

## Implementation Details
- Created relational tables with appropriate data types
- Established relationships between tables using foreign keys
- Implemented analytical queries to extract insights from the data
- Used table materialization to persist query outputs
- Execution controlled through a bash script to ensure reproducibility

## Technologies Used
- PostgreSQL
- SQL
- Bash scripting

## Key Skills Demonstrated
- Relational database modeling
- Schema normalization
- SQL query optimization
- Data integrity enforcement
- Handling large-scale datasets
